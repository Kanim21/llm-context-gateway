Context management for long-running agent loops, self-hosted and inspectable.

Agent Gateway sits between your agent and the OpenAI / Anthropic APIs as a local proxy. It masks stale tool output, compacts history at a token threshold, and stores everything it touches in SQLite with a reversible codec you can verify yourself — without ever mutating the cached prefix your provider is billing you for.

See measured benchmarks GitHub (self-hosted)

Non-negotiable rules

These are enforced in code and covered by tests — not aspirational.

  • Cache prefix immutability Every frozen prefix is checksummed with SHA-256 on registration. Any later mismatch raises CachePrefixMutationError instead of silently re-sending a broken cache.
  • Strict metric separation Token Reduction %, Cost Reduction %, and Call Reduction % are computed and reported independently. There is no blended "efficiency score" anywhere in this codebase.
  • Real tokenization only Counts come from named tokenizers — cl100k_base via tiktoken for OpenAI, a community-mirrored claude-bpe vocab for Anthropic. Character counts exist only as a secondary, storage-layer statistic.
  • Lossy passes default off Structural stripping, eco trimming, pruning, numeric quantization, and query filtering all require explicit opt-in. Measured faithfulness costs are published below, including the unflattering ones.
  • The storage codec never reaches the model .zclaw is an n-gram + DEFLATE codec that lives strictly inside the SQLite storage layer. The model only ever sees plain text; round-trip is verified byte-identical on every corpus payload in CI.

Modules

Organized by concern, not by feature branch.

core/

cache_boundary, observation_masking, compaction, blackboard, guardrails, routing, lossy_passes, tool_pruning, semantic_dedup, branch_collapse

adapters/

openai_adapter, anthropic_adapter — thin async httpx relays that extract and preserve the frozen prefix

proxy/

server (FastAPI, /v1/chat/completions, /v1/messages, /v1/metrics, /healthz), config, metrics

storage/

sqlite_store (blackboard + artifacts + metrics events), zclaw (reversible codec)

Benchmarks

Run against a 55-payload hand-authored corpus (prose, code, HTML, tables, agent transcripts, adversarial negations). Full methodology and raw numbers in BENCHMARKS.md and the interactive visualizer.

Round-trip proof

55/55 corpus payloads decode byte-identical through .zclaw. This is a pass/fail gate in CI, not a sampled estimate.

Faithfulness matrix

Per-pass, per-aggression-tier retention of numbers, dates, negations, and task-completion facts — including cases where retention drops to 0%.

Latency

Gateway-side processing overhead only (masking, compaction, guardrails), measured cold and warm across 1000 requests. Does not include upstream provider latency.

Cost model

An analytical simulation comparing four strategies across OpenAI and Anthropic pricing. Explicitly labeled illustrative, not live pricing.

Honesty notes

What this is not

This is not a claim that lossy passes are safe to enable by default — the faithfulness matrix shows pruning at MEDIUM/HIGH aggression drops task-completion retention to 0% on the adversarial corpus. It is not a claim that Docker builds were verified in a live registry pull — the local dev sandbox had no Docker daemon, so the Dockerfile is reviewed but not locally build-tested. The Claude tokenizer is a community-mirrored approximation, not Anthropic's literal production vocabulary. All cost figures are simulations against a fixed loop shape, not observed provider bills.

Agent Gateway — self-hosted, local-first. No telemetry leaves your machine.
